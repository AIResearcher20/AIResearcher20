## 📦 Featured Projects

### 🧬 [PathogenAgentAI](https://github.com/AIResearcher20/PathogenAgent)
Modular platform for biomedical data engineering and foundation model integration.
- Processed 8.99M ClinVar records → 4.2M+ analysis-ready variants
- BioGPT + LoRA/PEFT + RAG with UniProt and FAISS

### 🦠 [BioGPT-ClinVar](https://github.com/AIResearcher20/biogpt-clinvar)
Parameter-efficient fine-tuning of BioGPT on ClinVar-derived instruction data.
- 347M parameters · LoRA · BF16 · NVIDIA T4
- Public model, dataset, and PEFT adapter on Hugging Face

### 🧠 [OmniLatent](https://github.com/AIResearcher20/OmniLatent)
Deep autoencoder framework for transcriptomic representation learning.
- TCGA-BRCA: 1,231 samples × 23,375 genes
- 128-dimensional latent representations

### 📊 [LongiHealth](https://github.com/AIResearcher20/longihealth)
Reproducible longitudinal EHR analytics pipeline using MIMIC-IV.
- 12-module Python package · 11 pytest tests · Docker · CI
- Leakage-safe ML with patient-level splitting

### 🧪 [scp-bench](https://github.com/AIResearcher20/scp-bench)
Reproducible ML benchmarking framework for single-cell proteomics.
- LightGBM: 98.3% accuracy with permutation testing
- pip-installable · pytest · Docker · CI

### 🔬 [RACIPE-EMT-Project]
Integrative framework for EMT heterogeneity: ODE modeling, RACIPE ensembles, and transcriptomic validation.
- 9-state mechanistic ODE model (Tian 2013)
- 10,000 randomized RACIPE kinetic models
